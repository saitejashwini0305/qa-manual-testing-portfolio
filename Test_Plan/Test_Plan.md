
# Test Plan - SauceDemo

## Project Overview
This project focuses on testing the SauceDemo e-commerce application.

## Objective
To verify that the application functions correctly and provides a smooth user experience.

## Scope

### In Scope
- Login
- Logout
- Product Listing
- Add to Cart
- Remove from Cart
- Checkout Process

### Out of Scope
- Payment Gateway Integration
- Performance Testing
- Security Testing

## Testing Types
- Functional Testing
- Smoke Testing
- Regression Testing
- UI Testing

## Environment

Browser: Chrome

Operating System: Windows 11

Application URL:
https://www.saucedemo.com

## Deliverables

- Test Cases
- Bug Reports
- Test Execution Report
- Test Summary Report
