# Cart Test Cases

## TC011 - Add Single Product To Cart

Steps:
1. Login
2. Select product
3. Click Add To Cart

Expected Result:
Product added to cart.

## TC012 - Remove Product From Cart

Steps:
1. Add product
2. Open cart
3. Click Remove

Expected Result:
Product removed from cart.
